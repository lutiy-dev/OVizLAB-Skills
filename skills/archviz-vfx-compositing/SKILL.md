# archviz-vfx-compositing
## Trigger
Use for plan controlled architectural vfx and compositing such as weather, reflections, screen replacement and motion graphics. Follow repository AGENTS.md; skills guide work and do not imply installed software or verified output.
## Inputs
Plate/render passes, masks, tracking data if any, color-space settings, tools and approved effects.
## Procedure
1. Select minimum required effects and produce a shot-specific layer breakdown; preserve untouched architecture.
2. For added rain/fog/particles/shadow or reflection effects, define physical direction, depth ordering, motion blur and perspective consistency.
3. Composite with masks/IDs/depth, optical edges and stable tracking; avoid opaque AI replacement of building structure.
4. Check flicker, haloing, edge seams, temporal coherence, color mismatch and continuity across neighboring shots.
5. Document node graph, passes, versions, dependencies and render settings for repeatability.
## PASS / FAIL and reporting
Separate GENERATED, VALIDATED and TESTED. Report actual sources, versions, settings, evidence, observed render/export checks, unresolved risks and rollback. A planning document alone is not a tested film, image or scene.
## Stop conditions
PASS requires rendered frame-range review and approval; STOP on geometry drift, broken tracking, uncontrolled flicker or misleading visual claims.
