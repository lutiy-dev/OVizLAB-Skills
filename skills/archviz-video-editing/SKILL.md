# archviz-video-editing
## Trigger
Use for edit an architectural showreel or project film with narrative pacing, clean transitions, deliverable checks and audio rights. Follow repository AGENTS.md; skills guide work and do not imply installed software or verified output.
## Inputs
Approved footage/stills, frame rates, aspect ratios, target duration, audio/music licenses and delivery platform.
## Procedure
1. Build edit decision list: opening hero, progression, architectural reveals, details and closing call to action.
2. Define sequence FPS, source conforming, cuts, hold times, transition restraint and shot continuity.
3. Use original or appropriately licensed audio; normalize levels and check dialogue/mix if present.
4. Apply consistent color management, titles, logos, subtitles and safe margins; retain editable project and source files.
5. Render review proxies then final deliverables; inspect dropped frames, codecs, audio sync, readability and compression.
## PASS / FAIL and reporting
Separate GENERATED, VALIDATED and TESTED. Report actual sources, versions, settings, evidence, observed render/export checks, unresolved risks and rollback. A planning document alone is not a tested film, image or scene.
## Stop conditions
PASS requires watched review export and technical metadata QA; STOP on unlicensed audio, missing source media or unsafe destructive overwrite.
