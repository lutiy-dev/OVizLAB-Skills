# archviz-portfolio-director
## Trigger
Use for plan and curate a premium commercial architectural visualization portfolio with verifiable project claims. Follow repository AGENTS.md; skills guide work and do not imply installed software or verified output.
## Inputs
Portfolio brief, target clients, existing project imagery, usage rights, platform, intended services.
## Procedure
1. Inventory projects and image rights; distinguish client-approved work from internal demonstrations.
2. Score projects for architectural quality, narrative, composition, craft, recency and client relevance; do not invent commissions.
3. Choose hero projects, cover frame, sequence, supporting views and short case studies; prioritize exteriors and public space work.
4. Establish visual consistency while keeping project-specific design truthful; provide shot list and production backlog.
5. Approve only genuinely produced work and record audience-specific presentation variants.
## PASS / FAIL and reporting
Separate GENERATED, VALIDATED and TESTED. Report actual sources, versions, settings, evidence, observed render/export checks, unresolved risks and rollback. A planning document alone is not a tested film, image or scene.
## Stop conditions
PASS is a documented shortlist with source assets, rights, shot priorities and review notes. STOP on missing publication permission or fabricated project credentials.
